## Vision

### 10x Check
不仅是一个静态展示站点，而是一个活的技能发现引擎：AI 驱动的分析、自动分类、交互式学习路径。
用户输入仓库地址 → 30 秒内获得结构化的技能地图 + 智能摘要 + 学习建议。

### Platonic Ideal
"终于有人把散落在 GitHub 各处的 Claude Code 技能整理成了一个干净、结构化、可学习的知识库。
我只需要输入仓库地址，就能看到这个仓库里有什么好东西，怎么用，为什么这样设计。"

## Architecture

### 技术栈
- **Framework**: Next.js (App Router) + React
- **Styling**: Tailwind CSS (暗色模式优先)
- **Runtime**: Bun
- **AI**: Kimi API (sk-CcQh... 存储于 .env.local)
- **Code Highlight**: shiki
- **Markdown**: react-markdown + rehype-sanitize
- **Data**: JSON 文件缓存 (无 DB)

### 设计系统

#### 视觉风格: 终端风格 + 开发者气质
- 输入框模仿终端命令行 `$ analyze owner/repo`
- 信息密度优先，类似 GitHub issue list，不是 SaaS 营销页
- 分类标签用等宽文本 `[Skill]` `[Hook]` `[MCP]`，不用彩色药丸
- 技能详情用 Accordion 展开（点击展开/收起），不跳转新页面

#### Color System (暗色优先)
```
bg-primary:    #0d1117    bg-secondary:  #161b22    bg-tertiary:   #21262d
text-primary:  #e6edf3    text-secondary:#8b949e    text-muted:    #484f58
accent-green:  #3fb950    accent-blue:   #58a6ff    accent-orange: #d29922
accent-red:    #f85149    border:        #30363d
```

#### Typography
```
font-mono:  JetBrains Mono / Fira Code  (代码+输入框+标签)
font-sans:  Inter / system-ui           (正文)
font-cn:    "Noto Sans SC" / "PingFang SC" (中文)
```

#### Spacing: 4px base (xs:4 sm:8 md:16 lg:24 xl:32 2xl:48)
#### Border Radius: sm:4px md:6px lg:8px (克制，不用大圆角)
#### Animation: 骨架屏 pulse 2s, 过渡 150ms ease-in-out, Toast slide-up 200ms

### 响应式设计

| Viewport | Layout |
|----------|--------|
| Desktop (≥1024px) | 默认布局，单列满宽卡片 |
| Tablet (768-1023) | 减少 padding，导航收起为 hamburger |
| Mobile (<768px) | 全宽单列，学习路径横向 snap scroll，安装命令横滚 |

### Accessibility

- 输入框: aria-label="输入 GitHub 仓库地址", Enter 提交
- 仓库卡片: role="article", Tab 可聚焦
- Accordion: aria-expanded, Enter/Space 触发
- 复制按钮: aria-label="复制安装命令", 复制后 aria-live="polite"
- 进度条: role="progressbar", aria-valuenow
- 所有交互元素: 最小 44x44px touch target
- 颜色对比度: 所有文本 ≥ 4.5:1 (WCAG AA)

### 安全措施
- 仓库地址正则验证: `/^[a-zA-Z0-9._-]+\/[a-zA-Z0-9._-]+$/`
- Kimi API key 仅服务端使用，存储于 .env.local
- Markdown 渲染使用 rehype-sanitize 防 XSS
- Git clone 使用 `--depth=1` + 60s 超时

Hooks (基础) → Commands → Skills → MCP → Agents (高级)
